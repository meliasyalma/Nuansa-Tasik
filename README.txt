Nuansa Tasikmalaya — PROJECT UTS PEMROGRAMAN INTERNET
================================================

STRUKTUR PROJECT
- index.html             : Home / halaman utama
- wisata.html            : Katalog destinasi + pencarian + filter
- detail-wisata.html     : Detail destinasi + cuaca realtime Open-Meteo
- peta.html              : Peta interaktif Leaflet + OpenStreetMap
- trip-planner.html      : Perencana perjalanan + simulasi anggaran
- kuliner.html           : Informasi kuliner
- artikel.html           : Artikel dan tips wisata
- kontak.html            : Form kontak (mailto)
- css/syalma_style.css   : Seluruh stylesheet
- js/syalma_script.js    : Interaksi seluruh halaman
- assets/videos/         : Tempat video hero
- assets/images/         : Tempat aset gambar lokal

CARA MENJALANKAN
1. Ekstrak ZIP.
2. Buka folder Nuansa Tasikmalaya di Visual Studio Code.
3. Jalankan index.html dengan ekstensi Live Server.
4. Gunakan koneksi internet untuk font, gambar eksternal, Leaflet, peta, dan API cuaca.

VIDEO HERO
Simpan video MP4 wisata Tasikmalaya dengan nama wisata-tasik.mp4 di:
assets/videos/wisata-tasik.mp4
Video diputar otomatis tanpa suara dan berulang. Bila belum ada, poster gambar hero tetap tampil.

CATATAN PENTING SEBELUM DIKUMPULKAN
1. Beberapa foto adalah gambar ilustrasi dari Unsplash, bukan dokumentasi lokasi wisata yang disebutkan. Ganti dengan foto destinasi Tasikmalaya yang benar dan cantumkan sumber bila diperlukan.
2. Koordinat peta adalah titik referensi perkiraan untuk demonstrasi. Verifikasi koordinat akurat setiap lokasi sebelum dipublikasikan.
3. Jam operasional ditulis sebagai panduan umum/perlu konfirmasi, bukan data resmi yang dijamin selalu benar.
4. Cuaca detail menggunakan Open-Meteo API dan membutuhkan koneksi internet.
5. Form kontak menggunakan mailto dan membuka aplikasi email pengguna. Agar pesan masuk otomatis ke pengelola, perlu backend atau layanan form.
6. Estimasi biaya trip planner merupakan simulasi, bukan tarif tiket resmi.
7. Seluruh class dan ID buatan menggunakan awalan syalma_.
8. Tautan navigasi utama antar 8 halaman sudah disiapkan.

Dibuat sebagai project pembelajaran UTS Pemrograman Internet.
